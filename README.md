# WebCraft — новостной блог на Django

**WebCraft** — это некоммерческий pet-проект, созданный для практики веб-разработки на Django и Django REST Framework.

Проект представляет собой современный новостной блог с категориями, поиском, пагинацией и REST API для работы с комментариями.

## Возможности

- Просмотр списка новостей и отдельных публикаций
- Категории новостей
- Поиск по статьям
- Пагинация списка публикаций
- Система комментариев
- Добавление комментариев через REST API
- Получение комментариев через REST API
- Управление статьями, категориями и комментариями через Django Admin
- Адаптивный пользовательский интерфейс

## Технологии

## Как запустить

Убедитесь, что у вас установлен:

- Docker

### Клонирование репозитория

```bash
git clone https://github.com/strongardo/newsblog.git
cd newsblog
```

### Создание файла окружения

Создайте файл `.env` на основе шаблона:

```bash
cp .env.example .env
```

При необходимости измените настройки базы данных, секретный ключ и список разрешённых хостов.

### Сборка и запуск контейнеров

```bash
docker compose up --build
```

### Создание суперпользователя

```bash
docker compose exec web python manage.py createsuperuser
```

## Доступ к проекту

Главная страница:

```text
http://localhost:8000
```

Административная панель:

```text
http://localhost:8000/admin
```
